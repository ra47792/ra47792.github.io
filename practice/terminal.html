How to use vim

This is my page about using vim.

How to open vim

  1. Open the terminal.
  2. Type vim test.html.
  3. Press i to type.
  4. Write your HTML

Some HTML code

<h1>Hello!</h1>
<p>This is my page.</p>

You can use <p> to make a paragraph.

Keyboard

Press Esc when you are done typing.

Saving

Type :w to save your file.
